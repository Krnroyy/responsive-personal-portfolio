Read the waveform

Between 25,570 and 25,620 ns, mr=0 while mv=1. The payload stays at md=BE750F8E, mk=F, ml=1. READY rises at 25,620 ns; acceptance occurs at the rising edge at 25,625 ns. This is one observed interval, not a proof of all behaviour.

What happens under the hood?

The Web Crypto API generates a fresh 128-bit AES key and random 96-bit IV for each encryption. GCM appends a 128-bit authentication tag. Decryption must authenticate before this page displays a recovered image. The tampering test flips one ciphertext bit in a copy; the original encrypted bytes stay available for another valid decryption.

This lab encrypts compressed image file bytes, not the FPGA project's raw pixel stream. Keys and images stay in page memory; resetting clears this lab's references. This is a learning demo, with no key export or persistent storage.
