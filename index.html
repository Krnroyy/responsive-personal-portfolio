01 / RTL + VERIFICATION

AXI4-Stream FIFO

SystemVerilog

A parameterized beat FIFO that preserves data, TKEEP, and TLAST. Verification combines an independent scoreboard, directed and random stimulus, and formal safety checks.

across four depths

Bug injectionPop-without-ready caught

Formal scope: the documented configuration and harness assumptions; not every parameter value or full AXI conformance.

Read the waveform

Between 25,570 and 25,620 ns, mr=0 while mv=1. The payload stays at md=BE750F8E, mk=F, ml=1. READY rises at 25,620 ns; acceptance occurs at the rising edge at 25,625 ns. This is one observed interval, not a proof of all behaviour.

The signal-list values refer to an old cursor outside this window; the traces show the selected interval.

02 / FPGA SYSTEMS

AES-128-GCM image security

ZCU104

A Verilog accelerator integrated with AXI4-Stream, AXI DMA, and Cortex-A53 software. The project checks FPGA ciphertext and authentication tags against Python AESGCM and tests modified-ciphertext rejection.

  • Hardware/software co-design
  • Independent reference checks
  • Documented timing and resource results

An engineering research prototype. Results and limitations are documented separately for its baseline and protected-chunk architectures.

03 / CMOS DESIGN

CMOS 1-bit full adder

gpdk180

A hierarchical static CMOS full adder in Cadence Virtuoso, simulated with Spectre. The documentation includes all eight input combinations, waveforms, and output-load characterization.
