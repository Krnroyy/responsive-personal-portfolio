02 / FPGA SYSTEMS

AES-128-GCM image security

ZCU104

A Verilog accelerator integrated with AXI4-Stream, AXI DMA, and Cortex-A53 software. The project checks FPGA ciphertext and authentication tags against Python AESGCM and tests modified-ciphertext rejection.

  • Hardware/software co-design
  • Independent reference checks
  • Documented timing and resource results

An engineering research prototype. Results and limitations are documented separately for its baseline and protected-chunk architectures.

Repository ↗Measured results ↗Build guide ↗
03 / CMOS DESIGN

CMOS 1-bit full adder

gpdk180

A hierarchical static CMOS full adder in Cadence Virtuoso, simulated with Spectre. The documentation includes all eight input combinations, waveforms, and output-load characterization.

  • 180 nm generic process
  • 1.8 V nominal supply
  • Schematic-level simulation

Scope: schematic simulation and characterization. Physical layout, DRC, and LVS are outside this project.
